📊 AIdeaDeck – PDF to Summaries & Presentations 🚀

AIdeaDeck is an AI-powered tool that transforms research papers, study material, or any PDF into a bullet-point summary and a multi-slide PowerPoint presentation automatically.

✨ Features

📄 Upload any PDF file

🤖 AI-powered summarization (Google Gemini API)

📝 Clean & structured summaries with headings & bullet points

📊 Auto-generated PowerPoint presentation (PPTX)

🎨 Modern and responsive UI (React + Bootstrap)

🔥 Flask backend for PDF processing and AI integration

🛠️ Tech Stack

Frontend: React, Bootstrap

Backend: Flask, Python

AI Model: Google Gemini API

Others: PyPDF2, python-pptx, Flask-CORS

🚀 Getting Started
1️⃣ Clone the repository
git clone https://github.com/your-username/AIdeaDeck.git
cd AIdeaDeck

2️⃣ Setup Backend (Flask)
cd backend
pip install -r requirements.txt
python app.py

3️⃣ Setup Frontend (React)
cd frontend
npm install
npm start

4️⃣ Add your API Key
Create a .env file in the backend folder and add:
GEMINI_API_KEY=your_api_key_here
